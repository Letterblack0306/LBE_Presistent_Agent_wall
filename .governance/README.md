# Machine-readable governance

These files are authority inputs, not free-form notes.

- `workspace-policy.json` — workspace-wide policy and protected paths.
- `task-scope.json` — current task authorization. Default is inactive/read-only.
- `source-lifecycle.json` — source lifecycle declarations.
- `feature-ledger.json` — feature lifecycle declarations.

Do not modify governance authority as an after-the-fact way to legitimize implementation changes.
